## 1. Files and endpoint

```text
Controller: scripts\sdg2122x_control.py
Tests:      scripts\test_sdg2122x_control.py
Cache:      scripts\.sdg_device_cache.json
Endpoint:   <generator-ip>:5025, or cached/discovered endpoint
Protocol:   Raw TCP SCPI, LF-terminated ASCII
Identity:   Siglent Technologies,SDG1032X|SDG2122X,<serial>,<firmware>
```

Run the examples from the bundled `scripts/` directory. Its `192.0.2.213` default is a documentation-only TEST-NET address, not a real instrument endpoint.

The controller accepts compatible SIGLENT SDG models and loads a model profile after `*IDN?`. Generic SCPI devices are listed during discovery but receive only generic control.

Known profiles:

| Capability | SDG1032X | SDG2122X |
| --- | --- | --- |
| SINE/SQUARE maximum | 30 MHz | SINE 120 MHz |
| PULSE/RAMP/DDS ARB maximum | 12.5 MHz / 500 kHz / 6 MHz | Use the SDG2000X limits/readback |
| Arbitrary memory | 16,384 points | Device/firmware limit |
| `HARM`, `CMBN`, `MODE`, `FCNT` | Supported | Supported |
| `SRATE`, `CASCADE`, `COUP TRDUCH` | Blocked | Supported |
| `NOISE_ADD`, `MSW`, `POWER:ON:MODE`, `KEY` | Blocked | Blocked |

Structured APIs reject profiled frequency, memory, and unsupported-command violations before sending. Raw SCPI bypasses these client-side guards.

## 2. CLI

```text
tui catalog discover idn status sine output error raw
```

Read-only:

```powershell
python sdg2122x_control.py --host <generator-ip> idn
python sdg2122x_control.py --host <generator-ip> status
python sdg2122x_control.py status --channel 1
python sdg2122x_control.py error
```

Configure sine without changing output state:

```powershell
python sdg2122x_control.py sine --channel 1 --frequency 10k --amplitude 1 --offset 0 --phase 0
```

Output control:

```powershell
python sdg2122x_control.py output --channel 1 off
python sdg2122x_control.py output --channel 1 on
```

Important: omitting `--enable` from `sine` preserves the current output state. If the output was already ON, it stays ON. Turn it OFF explicitly before a safe reconfiguration.

Raw examples:

```powershell
python sdg2122x_control.py raw "C1:BSWV?"
python sdg2122x_control.py raw "C1:OUTP?"
python sdg2122x_control.py raw "C1:OUTP OFF"
```

## 3. Python API

Import:

```python
from sdg2122x_control import SiglentSDG, SineConfiguration
```

High-value methods:

- Connection: `connect`, `close`, `reconnect`, `identify`, `query`, `write`.
- Basic signal: `basic_waveform`, `set_sine`, `set_basic_wave`, `output_status`, `set_output`, `set_all_outputs`.
- Modes: `set_modulation`, `set_sweep`, `set_burst`.
- Arbitrary wave: `select_arbitrary`, `upload_waveform_csv`, `upload_waveform_samples`, `upload_waveform_hex`.
- Coordination: `equal_phase`, `copy_channel`, `set_sync`, `set_coupling`.
- Advanced: `set_sample_rate`, `set_harmonic`, `set_combine`, `set_frequency_counter`.
- System: clock, buzzer, protection, screen saver, startup, date/time, virtual keys, and network methods.

Use the structured method before raw SCPI. Read back the actual target channel after writes.

## 4. TUI

Launch with no arguments:

```powershell
python sdg2122x_control.py
```

The terminal UI contains 9 tabs: overview, channel, modulation, sweep, Burst, arbitrary wave, sync/advanced, system, and SCPI console. Action count is model-dependent; unsupported actions are hidden after identity detection.

Controls:

- `1`/`2`: change the current edit channel only.
- Arrow keys or mouse: select.
- Enter/F2: execute.
- F5/R: refresh.
- Esc/Q: exit.
- Mouse wheel/PageUp/PageDown: scroll.

Overview CH1/CH2 output actions always target the named channel, regardless of the current edit channel.

## 5. SCPI families

| Function | Family |
| --- | --- |
| Identity/sync/reset | `*IDN?`, `*OPC?`, `*RST`, `EQPHASE` |
| Basic waveform | `C<n>:BSWV` |
| Output | `C<n>:OUTP` |
| Modulation | `C<n>:MDWV` |
| Sweep | `C<n>:SWWV` |
| Burst | `C<n>:BTWV` |
| Arbitrary wave | `ARWV`, `STL?`, `WVDT` |
| Sync/coupling | `SYNC`, `COUP`, `MODE`; `CASCADE` only on supporting profiles |
| TrueArb/harmonic | `HARM`, `CMBN`; `SRATE` only on supporting profiles |
| Counter/system | `FCNT`, `BUZZ`, `SCSV`, `ROSC`, `SCFG` |
| LAN | `SYST:COMM:LAN:*` |

Amplitude `AMP` is Vpp. Confirm load configuration before comparing with scope readings.

## 6. Known behavior

- SDG2122X has been hardware-tested; SDG1032X support is based on the official SDG1000X data sheet/programming guide plus simulator regression tests until an endpoint is supplied.
- Some writes may take effect while leaving `-108,"Parameter not allowed"`; use readback plus the error queue.
- `CURRPRT?` and `VOLTSTAT?` may not respond on the tested SDG2122X firmware; avoid automatic polling.
- Arbitrary-wave Marker is disabled for SDG1032X/SDG2122X by the official command availability table.
- Network writes can immediately break the socket.
- SDG7000A-only Sequence, 16-channel digital, FHOP, IQ, and file-management features are not SDG1032X/SDG2122X features.

## 7. Safety and validation

- Never enable output during discovery or startup.
- Use OFF -> configure -> read back -> enable -> measure -> OFF for temporary tests.
- Confirm Vpp/Vrms/dBm, offset, phase, load, and channel before enabling.
- Run `python -m unittest -v test_sdg2122x_control.py` after controller changes; the suite includes SDG1032X profile, limit, feature-gating, and TUI-cropping coverage.
- Use real-device write tests only with explicit authorization.
