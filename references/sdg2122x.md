## 1. Files and endpoint

```text
Controller: <controller-directory>\sdg2122x_control.py
Tests:      <controller-directory>\test_sdg2122x_control.py
Cache:      <controller-directory>\.sdg_device_cache.json
Endpoint:   <generator-ip>:5025, or cached/discovered endpoint
Protocol:   Raw TCP SCPI, LF-terminated ASCII
Identity:   Siglent Technologies,SDG2122X,<serial>,<firmware>
```

The controller accepts compatible SIGLENT SDG models, not only SDG2122X. Generic SCPI devices are listed during discovery but receive only generic control.

## 2. CLI

```text
tui catalog discover idn status sine output error raw
```

Read-only:

```powershell
python sdg2122x_control.py --host <generator-ip> idn
python sdg2122x_control.py --host <generator-ip> status
python sdg2122x_control.py status --channel 1
python sdg2122x_control.py error
```

Configure sine without changing output state:

```powershell
python sdg2122x_control.py sine --channel 1 --frequency 10k --amplitude 1 --offset 0 --phase 0
```

Output control:

```powershell
python sdg2122x_control.py output --channel 1 off
python sdg2122x_control.py output --channel 1 on
```

Important: omitting `--enable` from `sine` preserves the current output state. If the output was already ON, it stays ON. Turn it OFF explicitly before a safe reconfiguration.

Raw examples:

```powershell
python sdg2122x_control.py raw "C1:BSWV?"
python sdg2122x_control.py raw "C1:OUTP?"
python sdg2122x_control.py raw "C1:OUTP OFF"
```

## 3. Python API

Import:

```python
from sdg2122x_control import SDG2122X, SineConfiguration
```

High-value methods:

- Connection: `connect`, `close`, `reconnect`, `identify`, `query`, `write`.
- Basic signal: `basic_waveform`, `set_sine`, `set_basic_wave`, `output_status`, `set_output`.
- Modes: `set_modulation`, `set_sweep`, `set_burst`.
- Arbitrary wave: `select_arbitrary`, `upload_waveform_csv`, `upload_waveform_samples`, `upload_waveform_hex`.
- Coordination: `equal_phase`, `copy_channel`, `set_sync`, `set_coupling`.
- Advanced: `set_sample_rate`, `set_harmonic`, `set_combine`, `set_frequency_counter`.
- System: clock, buzzer, protection, screen saver, startup, date/time, virtual keys, and network methods.

Use the structured method before raw SCPI. Read back the actual target channel after writes.

## 4. TUI

Launch with no arguments:

```powershell
python sdg2122x_control.py
```

The terminal UI contains 9 tabs and 179 actions: overview, channel, modulation, sweep, Burst, arbitrary wave, sync/advanced, system, and SCPI console.

Controls:

- `1`/`2`: change the current edit channel only.
- Arrow keys or mouse: select.
- Enter/F2: execute.
- F5/R: refresh.
- Esc/Q: exit.
- Mouse wheel/PageUp/PageDown: scroll.

Overview CH1/CH2 output actions always target the named channel, regardless of the current edit channel.

## 5. SCPI families

| Function | Family |
| --- | --- |
| Identity/sync/reset | `*IDN?`, `*OPC?`, `*RST`, `EQPHASE` |
| Basic waveform | `C<n>:BSWV` |
| Output | `C<n>:OUTP` |
| Modulation | `C<n>:MDWV` |
| Sweep | `C<n>:SWWV` |
| Burst | `C<n>:BTWV` |
| Arbitrary wave | `ARWV`, `STL?`, `WVDT` |
| Sync/coupling | `SYNC`, `COUP`, `MODE`, `CASCADE` |
| TrueArb/harmonic | `SRATE`, `HARM`, `CMBN` |
| Counter/system | `FCNT`, `BUZZ`, `SCSV`, `ROSC`, `SCFG` |
| LAN | `SYST:COMM:LAN:*` |

Amplitude `AMP` is Vpp. Confirm load configuration before comparing with scope readings.

## 6. Known behavior

- Current tested firmware: `2.01.01.35R3B2`.
- Some writes may take effect while leaving `-108,"Parameter not allowed"`; use readback plus the error queue.
- `CURRPRT?`, `VOLTSTAT?`, and arbitrary-wave Marker queries may not respond on this firmware; avoid automatic polling.
- Network writes can immediately break the socket.
- SDG7000A-only Sequence, 16-channel digital, FHOP, IQ, and file-management features are not SDG2122X features.

## 7. Safety and validation

- Never enable output during discovery or startup.
- Use OFF -> configure -> read back -> enable -> measure -> OFF for temporary tests.
- Confirm Vpp/Vrms/dBm, offset, phase, load, and channel before enabling.
- Run `python -m unittest -v test_sdg2122x_control.py` after controller changes.
- Use real-device write tests only with explicit authorization.
